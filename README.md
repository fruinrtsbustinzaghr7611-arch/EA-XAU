# 给设计师的使用方式（不用看代码）

你只需要做一件事：**双击脚本打开预览**。

## 你用 Windows

双击：`open-preview.bat`

## 你用 macOS

双击：`open-preview.command`

## 你用 Linux / 服务器

运行：

```bash
./start-preview.sh
```

然后打开：`http://127.0.0.1:4173/preview.html`

---

## 你会看到什么

- 黑金风格官网首页
- 首屏大标题与按钮
- 策略 / 表现 / 风控板块
- 动态数字和背景动画

---

## 如果没打开

- 先确认你在项目根目录
- 换地址：`http://localhost:4173/preview.html`
- 端口占用：`./start-preview.sh 8080`
